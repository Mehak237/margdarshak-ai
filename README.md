## 🌟 Overview & Mission
**Margdarshak AI** is an advanced, production-grade AI-powered career enablement platform engineered specifically to bridge the opportunity divide for **10 Million+ Indian engineering and degree students**, especially those from Tier-2 and Tier-3 institutions.

Unlike generic career tools, Margdarshak AI provides:
1. **Accurate Skill Gap Analysis** across **60+ top Indian companies and MNCs operating in India** (TCS, Infosys, Wipro, Amazon India, Flipkart, Zoho, Swiggy, PhonePe, CRED, etc.).
2. **25+ Verified Indian Central, State, and Corporate Scholarships** with a built-in **AI Statement of Purpose (SOP) Co-Pilot**.
3. **Interactive AI Mock Interviewer** with Speech Synthesis (voice read-out), Speech-to-Text, randomized authentic questions, and a detailed hiring scorecard with golden answers.
4. **Comprehensive Multilingual / Vernacular Support** across **9 Indian Languages** (*English, हिंदी, Hinglish, தமிழ், తెలుగు, ಕನ್ನಡ, বাংলা, मराठी, ગુજરાતી*).
5. **Unified Student Command Dashboard** tracking career readiness scores, bookmarked funding opportunities, resume scan trajectories, and interview scorecards.

## ⚡ 4 Killer Features

### 1. "Resume vs Dream Job" Gap Analyzer
- **Comprehensive Company & Role Search:** Search bar with live autocomplete across **60+ companies and 120+ roles**, plus a custom company/role entry box.
- **Flexible Resume Upload:** Drag-and-drop support for PDF/DOCX/TXT files, direct text pasting, and **3 quick sample resumes** (*Tier-3 CSE Fresher*, *Non-CS to Web Dev*, *Full-Stack MERN Dev*).
- **Animated Circular SVG Match Score:** Real-time percentage gauge (e.g. 68% Match) indicating candidate readiness level.
- **Skill Breakdown Badges:**
  - 🟢 **Matched Critical Skills** (Verified from resume)
  - 🔴 **Missing Required Skills** (Gaps that must be closed)
  - 🟡 **Recommended Edge Skills** (High-value bonus differentiators)
- **15-Day Personalized Action Roadmap:**
  - *Phase 1 (Days 1–5):* Foundations & Core Missing Fundamentals
  - *Phase 2 (Days 6–10):* Capstone Real-World Project & GitHub Implementation
  - *Phase 3 (Days 11–15):* System Design, STAR Stories & Resume Metric Rewriting
- **'Tell Me About Yourself' Pitch Evaluator:** Real-time AI diagnostic evaluating the student's 1-minute intro pitch against their chosen company/role, pinpointing strengths, missing points, and delivering an optimized, high-impact script.

---

### 2. Smart Scholarship Eligibility Engine + AI SOP Writer
- **25+ Verified Indian Schemes:** Includes AICTE Pragati, Reliance Foundation UG/PG, PMSS, Post-Matric SC/ST/OBC, HDFC Badhte Kadam, Tata Trusts, Kotak Kanya, CSSS Central Sector, L'Oréal Women in Science, ONGC, Siemens, Santoor, LIC Golden Jubilee, MahaDBT, Karnataka SSP, and UP Post-Matric.
- **Multi-Factor Filter Engine:** Instant matching based on:
  - *Annual Family Income (INR)*
  - *Academic Percentage (%)*
  - *Social Category (General, OBC, SC, ST, EWS)*
  - *Gender (All, Female-only schemes)*
  - *Domicile State (All 36 Indian States & UTs)*
  - *Course Level (B.Tech, Degree, Diploma, Postgraduate)*
- **AI SOP Co-Pilot:**
  - Interactive modal with 3 guided prompts: *Family background*, *Academic achievements*, and *Future career vision*.
  - Tone selector: *Academic & Formal*, *Resilient & Inspiring*, or *High-Impact Merit*.
  - Generates committee-ready, formal Statements of Purpose with 1-click Copy and 1-click Download (`.txt`).
  - 1-Click Bookmark to Student Dashboard.

---

### 3. Interactive AI Mock Interviewer with Live Scorecard
- **Company & Role Simulation:** Specific interview rubrics for TCS Prime/Digital/Ninja, Amazon SDE-1, Flipkart UI/Backend, Infosys SP, Zoho MTS, and FinTech Data Analysts.
- **Authentic Randomized Question Pool:** Each session draws **5 to 6 randomized technical, algorithmic, system design, project deep-dive, and behavioral questions**.
- **Voice & Speech Capabilities:**
  - **Speech Synthesis (Text-to-Speech):** Speaks questions aloud with natural voice.
  - **Speech Recognition (Voice Input):** Microphone toggle allows students to speak their answers.
  - **Sound Effects:** Zero-dependency Web Audio API chimes for question transitions and score generation.
- **Interactive Live Room:**
  - Question timer with visual countdown bar.
  - "Ask for a Clue / Hint" button providing technical nudges without spoiling answers.
- **Official Scorecard & Golden Responses:**
  - *Technical Accuracy Score (/10)*
  - *Confidence & Articulation Score (/10)*
  - *Problem Solving Depth (/10)*
  - *Simulated Hiring Verdict (e.g. Strong Hire, Conditional Hire, Needs Prep)*
  - Question-by-question breakdown showing: **Candidate's Answer**, **Key Strengths**, **Identified Mistakes / Areas to Fix**, and the **Ideal Golden Response**.

## 🛠️ Technology Stack
- **Architecture:** Zero-dependency, modern Vanilla JavaScript (ES6+), HTML5, and CSS3.
- **Styling:** Tailwind CSS with custom glassmorphism, responsive grids, and dark/light themes.
- **Icons:** Lucide Icons.
- **Audio & Speech:** Web Audio API (oscillators for chimes) and Web Speech API (`SpeechSynthesis` & `webkitSpeechRecognition`).
- **Persistence:** Browser `localStorage` for offline session persistence.

## 🚀 How to Run Locally

### Option 1: Using Node.js
```bash
# Inside d:\claude\margdarshak-ai
npm start
# Server will run at http://localhost:3000
```

### Option 2: Using Python
```bash
python server.py
# Server will run at http://localhost:3000
```

### Option 3: Direct Browser Open
Simply double-click `index.html` in any modern web browser.
